# Leistung (Threads, echter RAM, Lag-Protokoll) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Neuer Tab „Leistung": Auslastung der Java-Threads (vor allem `Server thread`), echter Heap und GC-Pausen aus dem GC-Log, und ein Lag-Protokoll, das jeden Lag mit wahrscheinlicher Ursache festhält — auch wenn niemand zuschaut.

**Architecture:** Neues Paket `internal/jvmstats` mit vier testbaren Teilen: Thread-Sampler über das Host-procfs (`/host/proc`, Wurzel injizierbar), GC-Log-Tailer/Parser (Pfad injizierbar), reiner Lag-Detektor mit Diagnose-Regeln und ein `Monitor`, der alle 5 s (fest, auch ohne Zuschauer) misst, Zeitreihen über den Collector in die bestehenden Sample-Tabellen schreibt, Lags in die neue Tabelle `lag_events` speichert (laufender Lag jeden Takt → MSM-Neustart verliert nichts) und ein SSE-Ereignis `perf` verteilt. Die API bekommt `GET /api/perf` und `GET /api/perf/lags`; `GET /api/history` lernt einen festen Zeitraum (`from`/`to`) und verdichtet lange Zeiträume. `Chart.svelte` wird rückwärtskompatibel um zweite Achse, Grenzlinien, Lag-Bänder und Zeiträume (1 h live / 6 h / 24 h / fester Lag-Zeitraum) erweitert.

**Tech Stack:** Go 1.26 (nur stdlib + vorhandenes `modernc.org/sqlite`), Svelte 5 (Runes), uPlot 1.6, `node --test` für reine JS-Hilfsfunktionen.

**Spec:** `docs/specs/2026-11-25-leistung-design.md` (Vault: „MSM – Leistung").

**Entscheidungen über die Spec hinaus (Spec-Absicht unverändert):**
- **MSPT als Zeitreihe:** Graph 1 braucht den MSPT-Verlauf, der bisher nicht gespeichert wird → `pollMC` schreibt zusätzlich `mc.mspt` (nur wenn online und > 0, sonst Lücke).
- **mc-Takt bleibt ohne Zuschauer bei 10 s:** Der Collector streckt alle Takte ohne Browser auf das 6-Fache. Für die Lag-Erkennung (MSPT-Auslöser) würde das 60 s bedeuten — gerade dann, wenn Lags unbeobachtet passieren. Der mc-Loop wird deshalb nicht mehr gestreckt (RCON `spark tps` alle 10 s, billig). Der `jvmstats`-Takt läuft eigenständig fest mit 5 s.
- **Frische MSPT-Werte:** Der 5-s-Takt übernimmt die MSPT nur, wenn seit dem letzten Takt ein neuer MC-Messwert kam (Zeitstempel) — ein Wert zählt nicht doppelt und hält keinen Lag künstlich offen.
- **Thread-Name aus `stat`:** Das Feld 2 von `task/<tid>/stat` ist identisch mit `task/<tid>/comm`; gelesen wird nur `stat` (halbiert die Datei-Zugriffe). Linux kürzt Thread-Namen auf 15 Zeichen.
- **GC-Log beim Start:** Der erste Lesevorgang liest nur die letzten 64 KB, übernimmt daraus den aktuellen Heap-Stand und meldet **keine** Pausen — alte Pausen dürfen keinen Lag auslösen.
- **Lag-Ende = Zeit des letzten Auslöse-Takts** (erkannt, sobald 30 s lang nichts mehr zutrifft). Beim CPU-Auslöser beginnt der Lag bei der ersten der beiden ≥ 95-%-Messungen. Ein CPU-„Zutreffen" verlangt immer zwei Messungen in Folge.
- **„Heap im schlimmsten Moment"** = der Takt mit der höchsten Heap-Belegung nach GC (Verhältnis) innerhalb des Lags; daraus auch der „Heap fast voll"-Zusatz.
- **Diagnose-Regel 3** vergleicht die Server-Thread-CPU im Takt der schlechtesten MSPT (ohne Thread-Messung keine Aussage). Trifft keine Regel zu, bleibt die Diagnose leer; die UI zeigt „keine eindeutige Ursache".
- **Lag-Speicherung:** `lag_events(id, start_ts, end_ts, detail JSON)` — alle Felder liegen als JSON in `detail`, Index-Spalten nur für Filter/Sortierung/Prune. Typen `LagEvent`/`ThreadGroup` leben in `jvmstats`; `storage` importiert sie (kein Zyklus: `jvmstats` → `collector`).
- **Verlauf für 6 h/24 h/Lag-Sprung:** `/api/history` akzeptiert `from`/`to` (Unix-Sekunden, max. 30 Tage) und verdichtet auf höchstens 1500 Punkte (Mittelwert je Eimer; bei `*.pause_max` das Maximum, sonst verschwänden Spitzen). Das Dashboard (1 h, ≤ 720 Punkte) ist davon nicht betroffen.
- **Byte-Umrechnung im Frontend:** Regel „Serie endet auf `.mem` **oder** beginnt mit `jvm.heap.`" → Bytes, Anzeige in GiB.
- **Mock-Modus:** kein Lag-Speicher (Monitor ohne Store, `/api/perf/lags` liefert `[]`); Threads/GC melden ihren Grund („/host/proc nicht lesbar" bzw. „GC-Log nicht eingeschaltet").

```go
func newProcFixture(t *testing.T) *procFixture {
	t.Helper()
	f := &procFixture{t: t, root: t.TempDir()}

// statLine erzeugt eine /proc/<pid>/stat-Zeile mit utime (Feld 14),
// stime (15) und starttime (22).
func statLine(pid int, comm string, ppid int, utime, stime, start uint64) string {
	return fmt.Sprintf("%d (%s) S %d %d %d 0 -1 4194560 0 0 0 0 %d %d 0 0 20 0 1 0 %d 0 0\n",
		pid, comm, ppid, pid, pid, utime, stime, start)
}

func (f *procFixture) write(rel, content string) {
	f.t.Helper()
	p := filepath.Join(f.root, rel)
	if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
		f.t.Fatal(err)
	}
	if err := os.WriteFile(p, []byte(content), 0o644); err != nil {
		f.t.Fatal(err)
	}
}

func (f *procFixture) proc(pid int, comm string, ppid int, start uint64) {
	f.write(filepath.Join(strconv.Itoa(pid), "stat"), statLine(pid, comm, ppid, 0, 0, start))

		statLine(tid, comm, pid, utime, stime, 0))
}
```

```go
// Package jvmstats misst die Java-Threads des Minecraft-Servers über das
// Host-procfs, liest das GC-Log der JVM (echter Heap, GC-Pausen) und
// erkennt Lags samt wahrscheinlicher Ursache.
package jvmstats

import (
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"
)

// ClkTck ist USER_HZ des Kernels (x86/arm64-Linux: 100); utime/stime in
// /proc/<pid>/stat zählen in diesen Ticks.
const ClkTck = 100

var (
	// ErrNoJava: kein Java-Prozess unter dem Container-Init (Server aus,
	// Neustart läuft) — der nächste Takt sucht neu.
	ErrNoJava = errors.New("Java-Prozess nicht gefunden")
	// ErrProcUnavailable: das Host-procfs ist nicht lesbar (Mount fehlt).
	ErrProcUnavailable = errors.New("/host/proc nicht lesbar")
)

type procStat struct {
	Comm      string
	PPID      int
	Ticks     uint64 // utime + stime
	StartTime uint64 // Start seit Boot in Ticks — erkennt PID-Wiederverwendung
}

// parseStat zerlegt eine /proc/<pid>/stat-Zeile. comm steht in Klammern und
// darf selbst Leerzeichen und Klammern enthalten — deshalb ab der LETZTEN ')'.
func parseStat(data string) (procStat, error) {
	open := strings.IndexByte(data, '(')
	end := strings.LastIndexByte(data, ')')
	if open < 0 || end < open {
		return procStat{}, fmt.Errorf("stat: unerwartetes Format")
	}
	// f[0]=state(3) f[1]=ppid(4) f[11]=utime(14) f[12]=stime(15) f[19]=starttime(22)
	f := strings.Fields(data[end+1:])
	if len(f) < 20 {
		return procStat{}, fmt.Errorf("stat: zu wenige Felder")
	}
	ppid, _ := strconv.Atoi(f[1])
	ut, _ := strconv.ParseUint(f[11], 10, 64)
	st, _ := strconv.ParseUint(f[12], 10, 64)
	start, _ := strconv.ParseUint(f[19], 10, 64)
	return procStat{Comm: data[open+1 : end], PPID: ppid, Ticks: ut + st, StartTime: start}, nil
}

func readStat(path string) (procStat, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return procStat{}, err
	}
	return parseStat(string(data))
}

// FindJava sucht ab initPID (Host-PID des Container-Init) den ersten Prozess
// mit comm "java" — initPID selbst oder ein Nachfahre (Breitensuche über
// das ppid-Feld aller /proc/*/stat). Liefert PID und starttime.
func FindJava(root string, initPID int) (int, uint64, error) {
	entries, err := os.ReadDir(root)
	if err != nil {
		return 0, 0, fmt.Errorf("%w: %v", ErrProcUnavailable, err)
	}
	stats := map[int]procStat{}
	children := map[int][]int{}
	for _, e := range entries {
		pid, err := strconv.Atoi(e.Name())
		if err != nil || !e.IsDir() {
			continue
		}
		st, err := readStat(filepath.Join(root, e.Name(), "stat"))
		if err != nil {
			continue // Prozess inzwischen beendet
		}
		stats[pid] = st
		children[st.PPID] = append(children[st.PPID], pid)
	}
	queue := []int{initPID}
	for len(queue) > 0 {
		pid := queue[0]
		queue = queue[1:]
		if st, ok := stats[pid]; ok && st.Comm == "java" {
			return pid, st.StartTime, nil
		}
		kids := children[pid]
		sort.Ints(kids)
		queue = append(queue, kids...)
	}
	return 0, 0, ErrNoJava
}

// HostCores zählt die cpuN-Zeilen in <root>/stat.
func HostCores(root string) (int, error) {
	data, err := os.ReadFile(filepath.Join(root, "stat"))
	if err != nil {
		return 0, err
	}
	n := 0
	for _, line := range strings.Split(string(data), "\n") {
		if len(line) > 3 && strings.HasPrefix(line, "cpu") && line[3] >= '0' && line[3] <= '9' {
			n++
		}
	}
	if n == 0 {
		return 0, fmt.Errorf("stat: keine cpuN-Zeilen")
	}
	return n, nil
}

type thread struct {
	comm  string
	ticks uint64
}

// readThreads liest Name und CPU-Ticks aller Threads von pid. Der Name kommt
// aus Feld 2 von task/<tid>/stat (identisch mit task/<tid>/comm, max. 15
// Zeichen) — eine Datei pro Thread statt zwei.
func readThreads(root string, pid int) (map[int]thread, error) {
	dir := filepath.Join(root, strconv.Itoa(pid), "task")
	entries, err := os.ReadDir(dir)
	if err != nil {
		return nil, err
	}
	out := make(map[int]thread, len(entries))
	for _, e := range entries {
		tid, err := strconv.Atoi(e.Name())
		if err != nil {
			continue
		}
		st, err := readStat(filepath.Join(dir, e.Name(), "stat"))
		if err != nil {
			continue // Thread inzwischen beendet
		}
		out[tid] = thread{comm: st.Comm, ticks: st.Ticks}
	}
	return out, nil
}
```

```go
package jvmstats

import (
	"context"
	"fmt"
	"path/filepath"
	"regexp"
	"sort"
	"strconv"
	"strings"
	"time"
)

// ThreadGroup fasst gleichnamige Threads zusammen (ohne laufende Nummer).
type ThreadGroup struct {
	Name  string  `json:"name"`
	Count int     `json:"count"`
	CPU   float64 `json:"cpu"` // Summe, % eines Kerns
}

// trailingIndex: laufende Nummer am Namensende samt Trenner (" #3", "#0", "-12").
var trailingIndex = regexp.MustCompile(`[\s#_-]*\d+$`)

// GroupName entfernt die laufende Nummer: "C2ME worker #3" → "C2ME worker",
// "GC Thread#0" → "GC Thread", "Worker-Main-12" → "Worker-Main".
func GroupName(comm string) string {
	name := strings.TrimSpace(trailingIndex.ReplaceAllString(comm, ""))
	if name == "" {
		return comm
	}
	return name
}

// ThreadSample ist die Auslastung eines Takts.
type ThreadSample struct {
	ServerCPU   float64       // Thread "Server thread", % eines Kerns
	ServerFound bool          // Thread "Server thread" existiert
	TotalCPU    float64       // alle Java-Threads, % eines Kerns
	Groups      []ThreadGroup // absteigend nach CPU
}

// ThreadSampler misst die Java-Threads Takt für Takt. Die Java-PID wird nie
// fest gespeichert: jeder Takt prüft per starttime, ob sie noch derselbe
// Prozess ist, sonst wird über die Container-Init-PID neu gesucht.
type ThreadSampler struct {
	root    string
	initPID func(context.Context) (int, error)
	pid     int
	start   uint64
	prev    map[int]thread
	prevAt  time.Time
}

func NewThreadSampler(root string, initPID func(context.Context) (int, error)) *ThreadSampler {
	return &ThreadSampler{root: root, initPID: initPID}
}

// Sample misst einen Takt. ok=false: erster Takt nach (Neu-)Fund des
// Prozesses — es gibt noch keinen Vergleichsstand.
func (s *ThreadSampler) Sample(ctx context.Context, now time.Time) (ThreadSample, bool, error) {
	if !s.stillValid() {
		s.pid, s.prev = 0, nil
		if s.initPID == nil {
			return ThreadSample{}, false, ErrNoJava
		}
		init, err := s.initPID(ctx)
		if err != nil {
			return ThreadSample{}, false, fmt.Errorf("%w: %v", ErrNoJava, err)
		}
		pid, start, err := FindJava(s.root, init)
		if err != nil {
			return ThreadSample{}, false, err
		}
		s.pid, s.start = pid, start
	}
	cur, err := readThreads(s.root, s.pid)
	if err != nil {
		s.pid, s.prev = 0, nil
		return ThreadSample{}, false, ErrNoJava
	}
	prev, prevAt := s.prev, s.prevAt
	s.prev, s.prevAt = cur, now
	dt := now.Sub(prevAt).Seconds()
	if prev == nil || dt <= 0 {
		return ThreadSample{}, false, nil
	}
	return compute(prev, cur, dt), true, nil
}

func (s *ThreadSampler) stillValid() bool {
	if s.pid == 0 {
		return false
	}
	st, err := readStat(filepath.Join(s.root, strconv.Itoa(s.pid), "stat"))
	return err == nil && st.StartTime == s.start && st.Comm == "java"
}

// compute: Auslastung = Δ(utime+stime) / Δt / CLK_TCK in % eines Kerns.
// Threads ohne Vorgängerstand (gerade gestartet) zählen mit 0 %.
func compute(prev, cur map[int]thread, dt float64) ThreadSample {
	var out ThreadSample
	groups := map[string]*ThreadGroup{}
	for tid, t := range cur {
		cpu := 0.0
		if p, ok := prev[tid]; ok && t.ticks >= p.ticks {
			cpu = float64(t.ticks-p.ticks) / ClkTck / dt * 100
		}
		out.TotalCPU += cpu
		if t.comm == "Server thread" {
			out.ServerCPU += cpu
			out.ServerFound = true
		}
		name := GroupName(t.comm)
		g := groups[name]
		if g == nil {
			g = &ThreadGroup{Name: name}
			groups[name] = g
		}
		g.Count++
		g.CPU += cpu
	}
	out.Groups = make([]ThreadGroup, 0, len(groups))
	for _, g := range groups {
		out.Groups = append(out.Groups, *g)
	}
	sort.Slice(out.Groups, func(i, j int) bool {
		if out.Groups[i].CPU != out.Groups[j].CPU {
			return out.Groups[i].CPU > out.Groups[j].CPU
		}
		return out.Groups[i].Name < out.Groups[j].Name
	})
	return out
}
```

```go
package jvmstats

import (
	"bytes"
	"errors"
	"io"
	"os"
	"regexp"
	"strconv"
	"strings"
)

// GCPause ist eine Stop-the-World-Pause aus dem GC-Log (-Xlog:gc).
type GCPause struct {
	Kind       string // Young, Mixed, Full, Remark, Cleanup, ...
	Before     uint64 // Heap vor der Pause, Bytes
	After      uint64 // Heap nach der Pause, Bytes
	Total      uint64 // Gesamt-Heap, Bytes
	DurationMs float64
}

// z. B. "GC(42) Pause Young (Normal) (G1 Evacuation Pause) 5000M->1200M(12288M) 12.345ms"
var pauseRe = regexp.MustCompile(`GC\(\d+\) Pause (\w+)(.*?) (\d+(?:\.\d+)?)([KMG])->(\d+(?:\.\d+)?)([KMG])\((\d+(?:\.\d+)?)([KMG])\) (\d+(?:\.\d+)?)ms`)

// ParseGCLine erkennt Pausen-Zeilen; alles andere (Concurrent-Phasen,
// Start-Infos, kaputte Zeilen) liefert ok=false.
func ParseGCLine(line string) (GCPause, bool) {
	m := pauseRe.FindStringSubmatch(line)
	if m == nil {
		return GCPause{}, false
	}
	dur, err := strconv.ParseFloat(m[9], 64)
	if err != nil {
		return GCPause{}, false
	}
	kind := m[1]
	if kind == "Young" && strings.Contains(m[2], "(Mixed)") {
		kind = "Mixed"
	}
	return GCPause{
		Kind:       kind,
		Before:     toBytes(m[3], m[4]),
		After:      toBytes(m[5], m[6]),
		Total:      toBytes(m[7], m[8]),
		DurationMs: dur,
	}, true
}

func toBytes(num, unit string) uint64 {
	v, _ := strconv.ParseFloat(num, 64)
	switch unit {
	case "K":
		v *= 1 << 10
	case "M":
		v *= 1 << 20
	case "G":
		v *= 1 << 30
	}
	return uint64(v)
}

const (
	maxReadPerPoll = 1 << 20  // höchstens 1 MB pro Takt
	primeWindow    = 64 << 10 // Vorlauf beim Start: nur das Dateiende
)

// GCTailer liest das GC-Log fortlaufend: Offset merken, bei gekürzter oder
// neuer Datei (Rotation) von vorn, abgeschnittene letzte Zeile bis zum
// nächsten Takt aufheben.
type GCTailer struct {
	path    string
	info    os.FileInfo // zuletzt gelesene Datei (Vergleich per os.SameFile)
	offset  int64
	partial []byte
	primed  bool
	last    GCPause
	hasLast bool
}

func NewGCTailer(path string) *GCTailer { return &GCTailer{path: path} }

// Last liefert die zuletzt gesehene Pause (auch aus dem Vorlauf).
func (t *GCTailer) Last() (GCPause, bool) { return t.last, t.hasLast }

// Poll liest neue vollständige Zeilen und liefert die gefundenen Pausen.
// Der erste erfolgreiche Aufruf liest nur die letzten 64 KB für den
// aktuellen Heap-Stand und liefert keine Pausen — alte Pausen dürfen
// keinen Lag auslösen.
func (t *GCTailer) Poll() ([]GCPause, error) {
	f, err := os.Open(t.path)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	info, err := f.Stat()
	if err != nil {
		return nil, err
	}
	priming := !t.primed
	switch {
	case priming:
		t.offset = max(0, info.Size()-primeWindow)
		t.partial = nil
	case t.info == nil || !os.SameFile(t.info, info) || info.Size() < t.offset:
		t.offset = 0 // rotiert, neu angelegt oder gekürzt → von vorn
		t.partial = nil
	}
	t.info = info
	t.primed = true
	startedMid := t.offset > 0
	n := min(info.Size()-t.offset, maxReadPerPoll)
	if n <= 0 {
		return nil, nil
	}
	buf := make([]byte, n)
	read, err := f.ReadAt(buf, t.offset)
	if err != nil && !errors.Is(err, io.EOF) {
		return nil, err
	}
	t.offset += int64(read)
	data := append(t.partial, buf[:read]...)
	lines := bytes.Split(data, []byte("\n"))
	t.partial = append([]byte(nil), lines[len(lines)-1]...)
	if len(t.partial) > maxReadPerPoll {
		t.partial = nil // Riesenzeile ohne Umbruch verwerfen
	}
	lines = lines[:len(lines)-1]
	if priming && startedMid && len(lines) > 0 {
		lines = lines[1:] // mitten in der Datei begonnen: erste Zeile angeschnitten
	}
	var out []GCPause
	for _, l := range lines {
		p, ok := ParseGCLine(strings.TrimRight(string(l), "\r"))
		if !ok {
			continue
		}
		t.last, t.hasLast = p, true
		out = append(out, p)
	}
	if priming {
		return nil, nil
	}
	return out, nil
}
```

```go
package jvmstats

import (
	"slices"
	"strings"
	"time"
)

// Grenzwerte der Lag-Erkennung (Spec „Leistung").
const (
	MSPTLimit      = 50.0             // ms pro Tick
	GCPauseLimit   = 100.0            // ms
	CPULimit       = 95.0             // % eines Kerns, zwei Messungen in Folge
	CPUWaitLimit   = 80.0             // darunter „wartet auf etwas"
	HeapFullRatio  = 0.85             // Heap nach GC
	LagQuiet       = 30 * time.Second // so lange ohne Auslöser → Lag vorbei
	topThreadCount = 5
)

// LagEvent ist ein Eintrag im Lag-Protokoll.
type LagEvent struct {
	ID           int64         `json:"id"`
	Start        time.Time     `json:"start"`
	End          time.Time     `json:"end"`      // letzter Takt mit Auslöser
	Trigger      string        `json:"trigger"`  // mspt | gc | cpu (erster Auslöser)
	Triggers     []string      `json:"triggers"` // alle, Reihenfolge des ersten Auftretens
	WorstMSPT    float64       `json:"worstMspt"`
	WorstTPS     float64       `json:"worstTps"` // 0 = keine TPS-Messung im Lag
	MaxGCPauseMs float64       `json:"maxGcPauseMs"`
	Players      int           `json:"players"`
	HeapAfterGC  uint64        `json:"heapAfterGc"` // im Moment der höchsten Belegung
	HeapTotal    uint64        `json:"heapTotal"`
	MaxServerCPU float64       `json:"maxServerCpu"`
	TopThreads   []ThreadGroup `json:"topThreads"` // Top 5 im Takt mit der höchsten Server-Thread-CPU
	Diagnosis    string        `json:"diagnosis"`
}

// clone kopiert inklusive Slices (der Detector ändert den laufenden Lag weiter).
func (e LagEvent) clone() LagEvent {
	e.Triggers = slices.Clone(e.Triggers)
	e.TopThreads = slices.Clone(e.TopThreads)
	return e
}

// Tick ist ein Messtakt (5 s) mit allem, was die Lag-Erkennung braucht.
type Tick struct {
	Time        time.Time
	ServerCPU   float64 // % eines Kerns
	HasCPU      bool    // Thread-Messung in diesem Takt vorhanden
	MSPT, TPS   float64
	HasMSPT     bool    // NEUER MC-Messwert in diesem Takt
	Players     int
	GCPauseMax  float64 // längste GC-Pause in diesem Takt, ms
	HeapAfterGC uint64  // 0 = unbekannt
	HeapTotal   uint64
	Groups      []ThreadGroup // absteigend nach CPU
}

// Findings fasst zusammen, was die Diagnose-Regeln brauchen.
type Findings struct {
	MaxServerCPU   float64
	MaxGCPauseMs   float64
	HeapRatio      float64 // Heap nach GC / gesamt im schlimmsten Moment
	WorstMSPT      float64
	CPUAtWorstMSPT float64 // Server-Thread-CPU im Takt der schlechtesten MSPT
	HasCPUAtWorst  bool
}

// Diagnose wendet die Regeln in fester Reihenfolge an; alle zutreffenden
// Texte, mit „; " verbunden. Leer = keine eindeutige Ursache.
func Diagnose(f Findings) string {
	var parts []string
	if f.MaxServerCPU >= CPULimit {
		parts = append(parts, "Spiellogik überlastet (Server-Thread am Anschlag)")
	}
	if f.MaxGCPauseMs > GCPauseLimit {
		s := "Speicherbereinigung hat den Server angehalten"
		if f.HeapRatio > HeapFullRatio {
			s += " — Heap fast voll"
		}
		parts = append(parts, s)
	}
	if f.WorstMSPT > MSPTLimit && f.HasCPUAtWorst && f.CPUAtWorstMSPT < CPUWaitLimit {
		parts = append(parts, "Server wartet auf etwas (z. B. Festplatte, Chunk-Laden)")
	}
	return strings.Join(parts, "; ")
}

// Detector fasst Auslöser zu Lags zusammen. Nicht nebenläufig benutzen.
type Detector struct {
	open          *LagEvent
	lastTrigger   time.Time
	cpuStreak     int
	cpuStart      time.Time
	cpuAtWorst    float64
	hasCPUAtWorst bool
}

func NewDetector() *Detector { return &Detector{} }

// Observe verarbeitet einen Takt. Liefert den laufenden oder gerade
// beendeten Lag (nil = kein Lag) und ob er mit diesem Takt beendet wurde.
// Der Zeiger bleibt über alle Takte eines Lags derselbe — eine beim
// Speichern vergebene ID bleibt so erhalten.
func (d *Detector) Observe(t Tick) (*LagEvent, bool) {
	if t.HasCPU && t.ServerCPU >= CPULimit {
		if d.cpuStreak == 0 {
			d.cpuStart = t.Time
		}
		d.cpuStreak++
	} else {
		d.cpuStreak = 0
	}
	var trig []string
	if t.HasMSPT && t.MSPT > MSPTLimit {
		trig = append(trig, "mspt")
	}
	if t.GCPauseMax > GCPauseLimit {
		trig = append(trig, "gc")
	}
	if d.cpuStreak >= 2 {
		trig = append(trig, "cpu")
	}

	if len(trig) == 0 {
		if d.open != nil && t.Time.Sub(d.lastTrigger) >= LagQuiet {
			ev := d.open
			d.open = nil
			return ev, true
		}
		return d.open, false
	}
	if d.open == nil {
		start := t.Time
		if slices.Contains(trig, "cpu") && d.cpuStart.Before(start) {
			start = d.cpuStart
		}
		d.open = &LagEvent{Start: start, Trigger: trig[0]}
		d.cpuAtWorst, d.hasCPUAtWorst = 0, false
	}
	e := d.open
	d.lastTrigger = t.Time
	e.End = t.Time
	for _, tr := range trig {
		if !slices.Contains(e.Triggers, tr) {
			e.Triggers = append(e.Triggers, tr)
		}
	}
	d.update(t)
	e.Diagnosis = Diagnose(Findings{
		MaxServerCPU:   e.MaxServerCPU,
		MaxGCPauseMs:   e.MaxGCPauseMs,
		HeapRatio:      heapRatio(e.HeapAfterGC, e.HeapTotal),
		WorstMSPT:      e.WorstMSPT,
		CPUAtWorstMSPT: d.cpuAtWorst,
		HasCPUAtWorst:  d.hasCPUAtWorst,
	})
	return e, false
}

func (d *Detector) update(t Tick) {
	e := d.open
	if t.HasMSPT {
		if t.MSPT > e.WorstMSPT {
			e.WorstMSPT = t.MSPT
			d.cpuAtWorst, d.hasCPUAtWorst = t.ServerCPU, t.HasCPU
		}
		if t.TPS > 0 && (e.WorstTPS == 0 || t.TPS < e.WorstTPS) {
			e.WorstTPS = t.TPS
		}
	}
	e.MaxGCPauseMs = max(e.MaxGCPauseMs, t.GCPauseMax)
	e.Players = max(e.Players, t.Players)
	if t.HeapTotal > 0 && (e.HeapTotal == 0 ||
		heapRatio(t.HeapAfterGC, t.HeapTotal) > heapRatio(e.HeapAfterGC, e.HeapTotal)) {
		e.HeapAfterGC, e.HeapTotal = t.HeapAfterGC, t.HeapTotal
	}
	if t.HasCPU && (e.TopThreads == nil || t.ServerCPU > e.MaxServerCPU) {
		e.MaxServerCPU = t.ServerCPU
		e.TopThreads = slices.Clone(t.Groups[:min(topThreadCount, len(t.Groups))])
	}
}

func heapRatio(after, total uint64) float64 {
	if total == 0 {
		return 0
	}
	return float64(after) / float64(total)
}
```

```go
// lagRetention: Lag-Protokoll so lange wie die Minutenwerte der Graphen.
const lagRetention = 30 * 24 * time.Hour

// Alle Felder eines Lags liegen als JSON in detail; start_ts/end_ts (Unix-
// Sekunden) dienen nur Filter, Sortierung und Prune.
func (s *SQLite) migrateLags() error {
	_, err := s.db.Exec(`
CREATE TABLE IF NOT EXISTS lag_events (
	id       INTEGER PRIMARY KEY AUTOINCREMENT,
	start_ts INTEGER NOT NULL,
	end_ts   INTEGER NOT NULL,
	detail   TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_lag_events_start ON lag_events(start_ts);`)
	return err
}

// SaveLag legt einen Lag an (ID 0 → neue ID in ev.ID) oder aktualisiert
// ihn. Der laufende Lag wird jeden Takt gespeichert — ein MSM-Neustart
// mitten im Lag verliert so nichts, der Eintrag behält sein bisheriges Ende.
func (s *SQLite) SaveLag(ctx context.Context, ev *jvmstats.LagEvent) error {
	detail, err := json.Marshal(ev)
	if err != nil {
		return err
	}
	if ev.ID == 0 {
		res, err := s.db.ExecContext(ctx,
			`INSERT INTO lag_events(start_ts, end_ts, detail) VALUES(?,?,?)`,
			ev.Start.Unix(), ev.End.Unix(), string(detail))
		if err != nil {
			return err
		}
		id, err := res.LastInsertId()
		if err != nil {
			return err
		}
		ev.ID = id
		return nil
	}
	_, err = s.db.ExecContext(ctx,
		`UPDATE lag_events SET start_ts=?, end_ts=?, detail=? WHERE id=?`,
		ev.Start.Unix(), ev.End.Unix(), string(detail), ev.ID)
	return err
}

// ListLags liefert Lags, die nach since endeten — neueste zuerst.
func (s *SQLite) ListLags(ctx context.Context, since time.Time, limit int) ([]jvmstats.LagEvent, error) {
	rows, err := s.db.QueryContext(ctx,
		`SELECT id, detail FROM lag_events WHERE end_ts >= ? ORDER BY start_ts DESC, id DESC LIMIT ?`,
		since.Unix(), limit)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	out := []jvmstats.LagEvent{}
	for rows.Next() {
		var id int64
		var detail string
		if err := rows.Scan(&id, &detail); err != nil {
			return nil, err
		}
		var ev jvmstats.LagEvent
		if err := json.Unmarshal([]byte(detail), &ev); err != nil {
			continue // kaputter Eintrag soll das Protokoll nicht sperren
		}
		ev.ID = id
		out = append(out, ev)
	}
	return out, rows.Err()
}
```

```go
// loop runs fn on the given interval; when no subscriber is connected the
// interval is stretched 6x to reduce idle load (samples still get stored) —
// außer stretch ist false.
func (c *Collector) loop(ctx context.Context, interval time.Duration, stretch bool, fn func(context.Context)) {
	fn(ctx)
	t := time.NewTimer(interval)
	defer t.Stop()
	for {
		t.Reset(nextInterval(interval, stretch, c.HasSubscribers()))
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			fn(ctx)
		}
	}
}

// nextInterval streckt den Takt ohne Zuschauer auf das 6-Fache, sofern die
// Schleife das erlaubt.
func nextInterval(interval time.Duration, stretch, watched bool) time.Duration {
	if stretch && !watched {
		return interval * 6
	}
	return interval
}
```

```go
	Reason string `json:"reason,omitempty"`

	GCLog           Availability  `json:"gcLog"`
	ServerThreadCPU *float64      `json:"serverThreadCpu"`

func NewMonitor(cfg Config, sink Sink, store LagStore, log *slog.Logger) *Monitor {
	if cfg.Interval <= 0 {
		cfg.Interval = 5 * time.Second
	}
	return &Monitor{
		cfg:     cfg,
		threads: NewThreadSampler(cfg.ProcRoot, cfg.InitPID),
		gc:      NewGCTailer(cfg.GCLogPath),
		det:     NewDetector(),
		sink:    sink,
		store:   store,
		log:     log,
		status:  Status{Groups: []ThreadGroup{}},
	}

// Run misst sofort und dann im festen Takt, bis ctx endet. Der laufende Lag
// ist zu diesem Zeitpunkt schon mit seinem bisherigen Ende gespeichert.
func (m *Monitor) Run(ctx context.Context) {
	m.Tick(ctx, time.Now())
	t := time.NewTicker(m.cfg.Interval)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case now := <-t.C:
			m.Tick(ctx, now)
		}
	}
}

// Tick ist ein Messtakt (für Tests exportiert).
func (m *Monitor) Tick(ctx context.Context, now time.Time) {
	st := Status{Time: now, Groups: []ThreadGroup{}}
	tick := Tick{Time: now}
	var samples []collector.Sample
	add := func(series string, v float64) {
		samples = append(samples, collector.Sample{Series: series, Time: now, Value: v})
	}

	if cores, err := HostCores(m.cfg.ProcRoot); err == nil {
		st.HostCores = cores
	}

	ts, ok, err := m.threads.Sample(ctx, now)
	if err != nil {
		st.Threads = Availability{Reason: threadReason(err)}
	} else {
		st.Threads = Availability{OK: true}
		if ok {
			java := ts.TotalCPU
			st.JavaCPU = &java
			add(SeriesJavaCPU, java)
			if ts.ServerFound {
				srv := ts.ServerCPU
				st.ServerThreadCPU = &srv
				tick.ServerCPU, tick.HasCPU = srv, true
				add(SeriesServerCPU, srv)
			}
			tick.Groups = ts.Groups
			st.Groups = ts.Groups[:min(TopGroups, len(ts.Groups))]
		}
	}

	pauses, err := m.gc.Poll()
	if err != nil {
		st.GCLog = Availability{Reason: gcReason(err)}
	} else {
		st.GCLog = Availability{OK: true}
		for _, p := range pauses {
			tick.GCPauseMax = max(tick.GCPauseMax, p.DurationMs)
		}
		gmax := tick.GCPauseMax
		st.GCPauseMax = &gmax
		add(SeriesGCPause, gmax)
		if last, ok := m.gc.Last(); ok {
			after, total, dur := last.After, last.Total, last.DurationMs
			st.HeapAfterGC, st.HeapTotal, st.LastGCPauseMs = &after, &total, &dur
			tick.HeapAfterGC, tick.HeapTotal = after, total
			add(SeriesHeapAfter, float64(after))
			add(SeriesHeapTotal, float64(total))
		}
	}

	if m.cfg.MC != nil {
		mc := m.cfg.MC()
		if mc.Online && mc.MSPT > 0 {
			v := mc.MSPT
			st.MSPT = &v
			// nur neue Messwerte zählen (mc-Takt 10 s, dieser Takt 5 s)
			if mc.Time.After(m.lastMC) {
				tick.MSPT, tick.TPS, tick.HasMSPT = mc.MSPT, mc.TPS, true
				m.lastMC = mc.Time
			}
		}
		tick.Players = mc.PlayersOnline
	}

	if ev, ended := m.det.Observe(tick); ev != nil {
		if m.store != nil {
			if err := m.store.SaveLag(ctx, ev); err != nil {
				m.log.Warn("save lag failed", "err", err)
			}
		}
		if !ended {
			open := ev.clone()
			st.OpenLag = &open
		}
	}

	m.mu.Lock()
	m.status = st
	m.mu.Unlock()
	if len(samples) > 0 {
		m.sink.Enqueue(samples...)
	}
	m.sink.Publish(collector.Event{Type: "perf", Data: st})
}

// Current liefert den Stand des letzten Takts.
func (m *Monitor) Current() Status {
	m.mu.RLock()
	defer m.mu.RUnlock()
	return m.status
}

// Lags liefert das Lag-Protokoll (ohne Store: leer).
func (m *Monitor) Lags(ctx context.Context, since time.Time, limit int) ([]LagEvent, error) {
	if m.store == nil {
		return []LagEvent{}, nil
	}
	return m.store.ListLags(ctx, since, limit)
}

func threadReason(err error) string {
	switch {
	case errors.Is(err, ErrProcUnavailable):
		return "/host/proc nicht lesbar"
	case errors.Is(err, ErrNoJava):
		return "Java-Prozess nicht gefunden (Server aus oder startet neu)"
	default:
		return err.Error()
	}
}

func gcReason(err error) string {
	if errors.Is(err, fs.ErrNotExist) {
		return "GC-Log nicht eingeschaltet"
	}
	return "GC-Log nicht lesbar: " + err.Error()
}
```

```go
type PerfSource interface {
	Current() jvmstats.Status
	Lags(ctx context.Context, since time.Time, limit int) ([]jvmstats.LagEvent, error)

const maxLags = 500

// handlePerf: aktueller Stand — Kacheln, Top-15-Thread-Gruppen, Verfügbarkeit.
func (s *Server) handlePerf(w http.ResponseWriter, r *http.Request) {
	writeJSON(w, http.StatusOK, s.perf.Current())

// handlePerfLags: /api/perf/lags?days=7 — Lag-Protokoll, neueste zuerst.
func (s *Server) handlePerfLags(w http.ResponseWriter, r *http.Request) {
	days := 7
	if d := r.URL.Query().Get("days"); d != "" {
		n, err := strconv.Atoi(d)
		if err != nil || n < 1 || n > 30 {
			httpError(w, http.StatusBadRequest, "invalid days parameter")
			return
		}
		days = n
	}
	since := time.Now().Add(-time.Duration(days) * 24 * time.Hour)
	lags, err := s.perf.Lags(r.Context(), since, maxLags)
	if err != nil {
		s.log.Error("lag query failed", "err", err)
		httpError(w, http.StatusInternalServerError, "query failed")
		return
	}
	if lags == nil {
		lags = []jvmstats.LagEvent{}
	}
	writeJSON(w, http.StatusOK, lags)
}
```

```go
// maxHistoryPoints begrenzt eine Verlaufs-Antwort (24 h im 5-s-Takt wären
// 17 280 Punkte je Serie). Die Dashboard-Stunde (≤ 720) bleibt unverändert.
const maxHistoryPoints = 1500

// handleHistory serves chart data: /api/history?series=host.cpu&hours=24
// oder mit festem Zeitraum &from=<unix>&to=<unix> (Lag-Ansicht im
// Leistung-Tab, höchstens 30 Tage).
func (s *Server) handleHistory(w http.ResponseWriter, r *http.Request) {
	q := r.URL.Query()
	series := q.Get("series")
	if series == "" {
		httpError(w, http.StatusBadRequest, "missing series parameter")
		return
	}
	hours := 24
	if h := q.Get("hours"); h != "" {
		if _, err := fmt.Sscanf(h, "%d", &hours); err != nil || hours < 1 || hours > 24*30 {
			httpError(w, http.StatusBadRequest, "invalid hours parameter")
			return
		}
	}
	to := time.Now()
	from := to.Add(-time.Duration(hours) * time.Hour)
	if q.Has("from") || q.Has("to") {
		fv, err1 := strconv.ParseInt(q.Get("from"), 10, 64)
		tv, err2 := strconv.ParseInt(q.Get("to"), 10, 64)
		if err1 != nil || err2 != nil || tv <= fv || tv-fv > 30*24*3600 {
			httpError(w, http.StatusBadRequest, "invalid from/to parameter")
			return
		}
		from, to = time.Unix(fv, 0), time.Unix(tv, 0)
	}
	samples, err := s.store.QuerySeries(r.Context(), series, from, to)
	if err != nil {
		s.log.Error("history query failed", "series", series, "err", err)
		httpError(w, http.StatusInternalServerError, "query failed")
		return
	}
	writeJSON(w, http.StatusOK, downsample(samples, maxHistoryPoints, strings.HasSuffix(series, ".pause_max")))
}

// downsample fasst lange Reihen auf höchstens limit Punkte zusammen: pro
// Eimer der Mittelwert, bei Spitzen-Serien (GC-Pausen) das Maximum — sonst
// verschwänden genau die Ausreißer. Zeitpunkt = letzter Punkt im Eimer.
func downsample(in []collector.Sample, limit int, peak bool) []collector.Sample {
	if limit <= 0 || len(in) <= limit {
		return in
	}
	size := (len(in) + limit - 1) / limit
	out := make([]collector.Sample, 0, limit)
	for i := 0; i < len(in); i += size {
		b := in[i:min(i+size, len(in))]
		sum, hi := 0.0, b[0].Value
		for _, s := range b {
			sum += s.Value
			hi = max(hi, s.Value)
		}
		v := sum / float64(len(b))
		if peak {
			v = hi
		}
		out = append(out, collector.Sample{Series: b[0].Series, Time: b[len(b)-1].Time, Value: v})
	}
	return out
}
```

```js
// Reine Datenaufbereitung für die Graphen (ohne Svelte, testbar mit node --test).

export const GiB = 1024 * 1024 * 1024

// Speicherwerte liegen in der DB in Bytes und werden in GiB gezeichnet:
// Container-/Host-RAM (*.mem) und der Java-Heap (jvm.heap.*)
export const isBytes = (key) => key.endsWith('.mem') || key.startsWith('jvm.heap.')

export const toChart = (key, v) => (v == null ? v : isBytes(key) ? v / GiB : v)

// typischer Abstand einer Serie (Median), daraus die Lückenschwelle:
// fehlen mehr als ~4 Messungen (Tab im Hintergrund, Standby, MSM aus),
// zeigt der Graph eine Lücke statt einer geraden Linie
export function gapSeconds(t) {
  if (t.length < 3) return Infinity
  const d = []
  for (let i = 1; i < t.length; i++) d.push(t[i] - t[i - 1])
  d.sort((a, b) => a - b)
  // mindestens 90 s: der Verlauf aus der DB ist gröber (30–60 s) als live (5 s)
  return Math.max(d[Math.floor(d.length / 2)] * 4, 90)
}

// Die Serien messen in unterschiedlichem Takt (Host, Container, Verlauf aus
// der DB gröber als live). Gemeinsame Zeitachse = alle Zeitpunkte aller
// Serien; jede Serie wird zwischen ihren eigenen Punkten linear ergänzt und
// nur bei echten Lücken unterbrochen (null + Marke direkt nach dem Punkt).
export function buildData(series, h) {
  const bufs = series.map((s) => h[s.key]).map((b) => (b && b.t.length ? b : null))
  if (!bufs[0]) return null
  const gaps = bufs.map((b) => (b ? gapSeconds(b.t) : Infinity))
  const axis = new Set()
  bufs.forEach((b, k) => {
    if (!b) return
    b.t.forEach((t, i) => {
      axis.add(t)
      if (i > 0 && t - b.t[i - 1] > gaps[k]) axis.add(b.t[i - 1] + 1)
    })
  })
  const xs = [...axis].sort((a, b) => a - b)
  const data = [xs]
  bufs.forEach((b, k) => {
    const col = []
    let j = 0
    for (const x of xs) {
      if (!b) { col.push(null); continue }
      while (j + 1 < b.t.length && b.t[j + 1] <= x) j++
      const t0 = b.t[j], v0 = b.v[j]
      if (t0 === x) { col.push(v0); continue }
      const t1 = b.t[j + 1], v1 = b.v[j + 1]
      if (t0 > x || t1 === undefined || t1 - t0 > gaps[k] || v0 == null || v1 == null) { col.push(null); continue }
      col.push(v0 + ((v1 - v0) * (x - t0)) / (t1 - t0))
    }
    data.push(col)
  })
  return data
}
```

```svelte
<script>
  import uPlot from 'uplot'
  import 'uplot/dist/uPlot.min.css'
  import { onMount } from 'svelte'
  import { writable } from 'svelte/store'
  import { history, track, fetchRange } from './stream.js'
  import { buildData } from './chartdata.js'

  // series: [{key, label, color, axis?}] — axis: 2 hängt die Serie an die
  // rechte Achse (unit2). Alle Props nach height sind optional: ohne sie
  // verhält sich der Graph wie bisher (Live-Stunde aus dem gemeinsamen
  // Verlauf, eine Achse) — die Dashboard-Graphen bleiben unverändert.
  // Zeitraum-Props werden nur beim Einbinden gelesen; zum Wechseln den
  // Graphen per {#key} neu einbinden.
  let {
    series = [],
    unit = '',
    height = 180,
    unit2 = '',      // Beschriftung der rechten Achse
    thresholds = [], // [{value, axis?: 1|2, color?}] gestrichelte Grenzlinie
    bands = [],      // [{from, to}] Unix-Sekunden, rot hinterlegt (Lags)
    hours = null,    // gleitender Zeitraum in Stunden aus /api/history (lädt alle 60 s neu)
    from = null,     // fester Zeitraum in Unix-Sekunden (mit to), z. B. ein Lag
    to = null,
  } = $props()

  let el
  let plot = null
  let win = null // Zeitfenster im Abruf-Modus: x-Achse zeigt genau diesen Bereich

  // Achsenbereich so wählen, dass die Grenzlinien immer sichtbar sind
  function scaleRange(axis) {
    const limits = thresholds.filter((t) => (t.axis ?? 1) === axis).map((t) => t.value)
    if (!limits.length) return null
    return (u, min, max) => [Math.min(0, min ?? 0), Math.max(max ?? 0, ...limits) * 1.1]
  }

  function drawBands(u) {
    if (!bands.length) return
    const { left, top, width, height: h } = u.bbox
    const ctx = u.ctx
    ctx.save()
    ctx.fillStyle = 'rgba(248, 113, 113, 0.18)'
    for (const b of bands) {
      const x0 = u.valToPos(b.from, 'x', true)
      const x1 = u.valToPos(b.to, 'x', true)
      if (x1 < left || x0 > left + width) continue
      const a = Math.max(x0, left)
      const z = Math.min(x1, left + width)
      // sehr kurze Lags trotzdem sichtbar (mind. 3 px)
      ctx.fillRect(a, top, Math.max(z - a, 3), h)
    }
    ctx.restore()
  }

  function drawThresholds(u) {
    if (!thresholds.length) return
    const { left, top, width, height: h } = u.bbox
    const ctx = u.ctx
    ctx.save()
    ctx.setLineDash([6, 4])
    ctx.lineWidth = 1.5
    for (const th of thresholds) {
      const scale = th.axis === 2 ? 'y2' : 'y'
      if (u.scales[scale]?.min == null) continue
      const y = u.valToPos(th.value, scale, true)
      if (y < top || y > top + h) continue
      ctx.strokeStyle = th.color ?? '#f87171'
      ctx.beginPath()
      ctx.moveTo(left, y)
      ctx.lineTo(left + width, y)
      ctx.stroke()
    }
    ctx.restore()
  }

  onMount(() => {
    const keys = series.map((s) => s.key)
    const fixed = from != null || hours != null
    const hasY2 = series.some((s) => s.axis === 2)

    const scales = { x: { time: true } }
    if (fixed) scales.x.range = (u, min, max) => (win ? [win.from, win.to] : [min, max])
    const r1 = scaleRange(1)
    const r2 = scaleRange(2)
    if (r1) scales.y = { range: r1 }
    if (hasY2) scales.y2 = r2 ? { range: r2 } : {}

    const axes = [
      { stroke: '#8b949e', grid: { stroke: '#2a323c' }, ticks: { stroke: '#2a323c' } },
      {
        stroke: '#8b949e',
        grid: { stroke: '#2a323c' },
        ticks: { stroke: '#2a323c' },
        label: unit,
        labelGap: 8,
      },
    ]
    if (hasY2) {
      axes.push({
        scale: 'y2',
        side: 1,
        stroke: '#8b949e',
        grid: { show: false },
        ticks: { stroke: '#2a323c' },
        label: unit2,
        labelGap: 8,
      })
    }

    const opts = {
      width: el.clientWidth,
      height,
      cursor: { drag: { setScale: false } },
      select: { show: false },
      legend: { live: true },
      scales,
      axes,
      series: [
        {},
        ...series.map((s) => ({
          label: s.label,
          stroke: s.color,
          width: 1.5,
          // Lücken (Leerzeile aus buildData) bleiben sichtbar
          spanGaps: false,
          ...(s.axis === 2 ? { scale: 'y2' } : {}),
        })),
      ],
      hooks: {
        drawClear: [drawBands], // hinter den Linien
        draw: [drawThresholds],
      },
    }
    const empty = [[], ...series.map(() => [])]
    plot = new uPlot(opts, empty, el)

    // Live: gemeinsamer Verlauf (SSE + vorgeladene Stunde);
    // Abruf-Modus: eigener Speicher aus /api/history
    const source = fixed ? writable({}) : history
    if (!fixed) track(keys)
    const unsub = source.subscribe((h) => {
      const data = buildData(series, h)
      if (data && plot) plot.setData(data)
      else if (fixed && plot) plot.setData(empty)
    })

    let timer = null
    async function load() {
      const now = Math.floor(Date.now() / 1000)
      win = from != null ? { from, to: to ?? now } : { from: now - hours * 3600, to: now }
      source.set(await fetchRange(keys, win.from, win.to))
    }
    if (fixed) {
      load()
      if (from == null) timer = setInterval(load, 60_000)
    }

    const ro = new ResizeObserver(() => {
      if (plot && el) plot.setSize({ width: el.clientWidth, height })
    })
    ro.observe(el)

    return () => {
      unsub()
      clearInterval(timer)
      ro.disconnect()
      plot?.destroy()
      plot = null
    }
  })

  // Lag-Bänder/Grenzlinien neu zeichnen, wenn sich die Listen ändern
  $effect(() => {
    bands
    thresholds
    plot?.redraw(false)
  })
</script>

<div class="chart-wrap" bind:this={el}></div>
```

```js
// Reine Hilfsfunktionen des Leistung-Tabs (testbar mit node --test).
import { GiB } from './chartdata.js'

export const fmtNum = (v) => v.toLocaleString('de-DE', { maximumFractionDigits: 1 })

// „5,2 von 12 GiB"
export function fmtHeap(after, total) {
  if (after == null || total == null) return '—'
  return `${fmtNum(after / GiB)} von ${fmtNum(total / GiB)} GiB`
}

// MSPT-Kachel: grün < 40, gelb < 50, rot ≥ 50 ms
export function msptClass(ms) {
  if (ms == null) return ''
  return ms < 40 ? 'ok' : ms < 50 ? 'warn' : 'err'
}

export function fmtDuration(start, end) {
  const s = Math.round((new Date(end) - new Date(start)) / 1000)
  if (s < 5) return '< 5 s'
  if (s < 60) return `${s} s`
  return `${Math.floor(s / 60)} min ${s % 60} s`
}

const TRIGGERS = { mspt: 'MSPT', gc: 'GC-Pause', cpu: 'Server-Thread' }
export const triggerLabel = (t) => TRIGGERS[t] ?? t

// kurze Erklärung der wichtigen Threads
const HINTS = [
  [/^Server thread$/, 'Spielwelt'],
  [/^Netty/, 'Netzwerk'],
  [/^(C2ME|Worker-Main)/, 'Chunks'],
  [/^(GC Thread|G1 )/, 'Speicher aufräumen'],
]
export function threadHint(name) {
  for (const [re, txt] of HINTS) if (re.test(name)) return txt
  return ''
}

const toSec = (iso) => Math.floor(new Date(iso).getTime() / 1000)

// Lag-Zeiträume für die roten Bänder; der laufende Lag kommt live dazu
export function lagBands(lags, openLag) {
  const all = [...(lags ?? [])]
  if (openLag && !all.some((l) => l.id === openLag.id)) all.push(openLag)
  return all.map((l) => ({ from: toSec(l.start), to: toSec(l.end) }))
}

// Zeitraum der Graphen nach Klick auf einen Lag
export function lagWindow(lag, padSec = 300) {
  return { from: toSec(lag.start) - padSec, to: toSec(lag.end) + padSec }
}
```
